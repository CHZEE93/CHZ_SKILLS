# Pallet 화면 패턴

각 패턴은 영상에서 관찰한 구조이다. 괄호 안은 근거 프레임(`영상ID@초`)이다. 클래스 이름은 [assets/pallet.css](../assets/pallet.css)를 기준으로 한다.

## 1. 앱 셸

- **내비** `.p-nav`: 맨 위에 기관 전환기(로고 원 + 이름 + ⇕, 테두리 박스)가 있다. 메뉴 순서는 `홈, 차트, 검사⌄, 예약, 통계⌄, 청구, 마약류⌄, 라이브러리⌄, (건강검진⌄), CRM, (전자서명⌄), 관리⌄, 설정⌄`이다. 하위 메뉴가 있는 항목은 오른쪽에 ⌄를 붙인다. 활성 항목은 tint 배경에 파랑 아이콘·글자를 쓴다. 하단에는 버전 문구, `메뉴 접기`, 구분선, `환경설정`, `로그아웃`을 둔다. (PrtRnLLTnOM@25, 335HY52YPGA@67)
- **상단바** `.p-top`: 페이지 제목, 회색 채움 검색(`환자 검색`), 아웃라인 파랑 `👤+ 신규환자`를 두고 오른쪽에 알림과 이니셜 아바타를 둔다. 예약 화면에서는 검색이 `환자 및 예약현황 검색`, 버튼이 `신환예약`이 된다. (jHWTogR7JSc@109)
- **페이지 탭**: 제목 아래 텍스트 탭을 두고 활성 탭은 검정 2px 밑줄로 표시한다(`대기리스트 / 스케줄 / 방문목적 / 수탁기관`). 패널 안의 하위 탭은 파랑 글자 + 파랑 밑줄이다. (jHWTogR7JSc@13)
- **홈**: 날짜 한 줄, 큰 시계(`11:31 am`), 인사말, 일러스트, 월간 리포트 봉투 카드로 구성한다. 업무 화면과 달리 여백이 넓다. (PrtRnLLTnOM@13, 335HY52YPGA@1)

## 2. 대상 목록(대기열)

- 헤더 `환자리스트` + 현황판 아이콘. 그 아래 카운터 탭 `대기 6 · 예약 0 · 방문 2`와 오른쪽 정렬 필터 `진료실01외 4 ⌄`를 둔다.
- **그룹 카드** `.p-group`: 흰 카드, 1px 선, radius 6. 헤더(옅은 회색, 38px)에는 담당자 이니셜 아바타, 그룹명, 인원수, ▲ 접기를 둔다. 담당자가 없는 장소(방사선실, 수납실, 태블릿접수)는 아바타를 생략한다.
- **행** `.p-row2`: 1줄은 `이름`(신규면 뒤에 빨간 점) + 오른쪽 상태, 2줄은 `성별 나이 ✚ 진료목적`이다. 선택 행은 `✓ 이름` 파랑 + tint 배경이다.
- 빈 그룹: `대기 환자가 없습니다.`(회색 11px). 숨기지 않는다.
- 새로 도착한 행과 이동한 행은 잠깐 깜빡인다(파랑/연분홍 하이라이트). 다른 역할의 화면에서 도착을 알아차리는 신호다. (Jn_sfEzZ7hg@4)
- 행 클릭 → 컨텍스트 메뉴 `'수납실'로 보내기` 등(현재 그룹 제외, 텍스트만, 그림자) → 이동 + 토스트 `김OO님을 '진료실02'(으)로 보냈습니다.` (WKeU2Z4ebLU@16, @19)
- 태블릿·모바일 접수 신청은 별도 그룹에 빨강 아웃라인 칩 `접수신청`을 붙여 쌓는다. (Jfi246Juez8@76)

## 3. 빈 작업면 = 다음 행동

대상을 선택하지 않았을 때 캔버스 가운데에 일러스트와 카드 3장을 둔다. (PrtRnLLTnOM@25)
1. 현재 대상 카드(폭 넓음, radius 12): `진료실01 ▾`, `다음 환자 부르기` 링크, 큰 이름, 칩, 담당자, 오른쪽 아래 `차트열기`(회색 채움) `진행하기`(파랑).
2. `신규환자를 등록하시겠습니까?` + 작은 tint 버튼.
3. `접수신청 (0)` + 원형 카운트 배지 + `접수 신청 건이 없습니다.`

## 4. 한 건 작업면(차트)

- **헤더 요약 바** `.p-summary`: `👤 번호 이름 성별, 나이 (생년월일) #태그` │ 칩 `건강보험` `일반진료` `🩺 담당의` │ `🌡 체온 36.8 체중 80 신장 182 (날짜)` │ `⚠ 주의` `👶 가족` … `✕ 닫기`. 각 항목은 hover하면 미리보기(바이탈 이력 테이블, 툴팁), click하면 편집 모달이 열린다. (WKeU2Z4ebLU@46–73)
- **이력 열**: 방문 카드(`날짜 (n일전)`, 담당의, 칩, ⌄ 접기). 펼치면 기록 요약과 상병·처치·처방 행이 나온다. 하단에 고정 `✏ 새 차트 생성` 아웃라인 버튼과 페이지네이션 `12개 중 1-10`을 둔다.
- **작업 카드** `.p-card`(1px 선, radius 6)를 세로로 쌓는다.
  - `진료기록`: 자유 텍스트, 오른쪽에 이미지 영역(`이미지를 드래그해서 업로드하세요`, `사진 업로드 (0/30)`), 하단에 자주 쓰는 문구 칩과 `더보기`. (7B7kH7m03RA@16)
  - `진단 및 처방`: 툴바(`예방접종`, `스마트관리료 ▾`, `DUR 점검`, `심사점검`, ⚙), 밑줄형 `오더 검색`, 섹션 고정 리스트(5절 참고).
  - `수납내역`: 회색 서브박스 3개(금액 트리 / 수납 기록 + `+ 수납 추가` / `남은 금액` 파랑). 라벨은 왼쪽, 금액은 오른쪽 bold + `원`. (Jn_sfEzZ7hg@22)
  - `문서발급`: 헤더에 `전체 미리보기 · 전체 발급 · ⚙`, 문서 행 + 상태 칩 `발급완료`, `+ 영수증 추가`. 발급 후 헤더 액션이 `전체 출력`으로 바뀐다. (Jn_sfEzZ7hg@43)
- **화면 구성 팝오버**: ⣿ 아이콘 아래 체크리스트(`진료기록 ✓ / 진단 및 처방 ✓ / 수납 ✓ / 문서발급 ✓`) + 풀폭 `확인`. (WKeU2Z4ebLU@91)
- **하단 액션 바** `.p-actionbar`: 왼쪽 `▯ 진료실01`(현재 위치)와 `진료 완료 ⋯`, 오른쪽 `[수납실 ⌄][대기 ⌄][▶ 보내기]`. 목적지 드롭업의 마지막 항목은 빨강 `병원에서 내보내기`다. (Jn_sfEzZ7hg@61)
- **참고 열(오더세트)**: 검색 + 폴더 트리 또는 2열 마스터-디테일(폴더 | 세트). 선택한 세트를 미리 보여 주고 `n 모두복사`로 일괄 삽입한다. 항목을 클릭하면 하나씩 삽입된다. (bX437bPd6pk@31, 0z9cgDYJXLE@259)
- **협업 열(환자기록)**: 보조 표면 배경, 상단 고정 공지 바 `📢 …`, 날짜 구분선, 메시지(아바타·이름 bold·시간 회색·🔖), 본문의 `@멘션` bold, `✓ 2` 읽음 수. hover하면 `☺ 🔖 ⋯`가 나오고 `⋯`에는 `기록 수정 / 기록 삭제 / 공지로 등록`이 있다. 하단에 입력창과 정사각 파랑 ✏ 버튼을 둔다. 팀 메모는 진료기록이나 승인 기록을 대신하지 않는다. (WKeU2Z4ebLU@109–145)
- **아이콘 레일**: 💬 기록 · 📢 공지 목록 · 🔖 북마크 · 🧪 검사결과. 활성 아이콘은 파랑이고, 협업 열 내용이 교체된다.

## 5. 반복 행 입력(처방 리스트)

- 고정 순서: ① 상병(✚, `코드 + 이름`, 주상병 오른쪽 초록 `주`, 비어 있으면 빨강 placeholder `주상병을 입력해주세요.`) → ② 진찰료(◇, 자동 산정 pill `스마트진찰료`, 오른쪽 `새로고침`) → ③ 약·재료(알약, 회색 코드 + 이름 말줄임, 단가, 인라인 수량 3칸, `용법`) → ④ 촬영·검사(카메라, 2줄) → ⑤ 문서(문서 아이콘). (bX437bPd6pk@34)
- 수량 칸 `.p-qty`: 폭 50, 아래 1px 밑줄만 있고, 숫자는 가운데 정렬한다. 열 제목 없이 순서(용량·일투·일수)로 읽는다. 라이브러리 편집 모달에서는 같은 값을 `용량* | 일투* | 일수*`로 라벨을 붙여 보여 준다.
- 구분 라벨은 배경 없는 컬러 글자로 쓴다(`비급여` 빨강, `원내` 보라).
- 행을 추가하면 토스트 `처방을 추가했습니다.`가 뜨고, 처방전 문서 행이 자동으로 생기고, 수납 금액이 갱신된다. (bX437bPd6pk@19, @22)

## 6. 통합 검색

- 입력창이 그 자리에서 팝오버로 넓어진다(약 600px, radius 8, 그림자). (PrtRnLLTnOM@91)
- 탭 `전체(요약) | 상병 | 오더 | 오더세트 | 처방아이템 | 단축어`(활성은 파랑 글자). 그룹 소제목 오른쪽에 `더보기`. 일치 부분은 노란 형광. `/` 입력은 단축어 호출이다. (0z9cgDYJXLE@274)
- 사람 검색 결과 행(2줄): `이름(일치 파랑) • 성별, 나이 🔗 소속` + 오른쪽 `최근방문 오늘 10:16` / 회색 칩 `no. 113912` `☎ 010-…` `990909-1••••••`. 우클릭하면 `예약하기 / 접수하기`가 나온다.
- 상태별 문구: 처음에는 `✍ 청구코드, 국문명칭, 주성분코드로 검색해보세요.`, 결과가 없으면 `ⓘ 해당하는 아이템이 없습니다.`, 미등록이면 하단에 고정 안내와 `신환예약` CTA를 둔다. (0z9cgDYJXLE@97, jHWTogR7JSc@193)

## 7. 폼과 모달

- **2열 등록 모달**: 왼쪽에 식별 폼(이름*, 주민번호 앞/뒤 + `☐ 주민등록번호가 없습니다.`, 그 아래 ✅ 자격조회 결과, 연락처 2열, 주소 + `검색`), 오른쪽에 테두리 박스(분류 멀티셀렉트 칩, 관계 `+`, 약관 전체 동의 그룹). 푸터는 `취소` │ `등록완료`(아웃라인) `등록 후 접수`(채움)이다. 수정 모드에서도 같은 폼을 쓰고 푸터만 `취소` `수정`으로 바꾼다. (PrtRnLLTnOM@34, WKeU2Z4ebLU@52)
- **맥락 패널 모달**: 왼쪽 약 280px 보조 표면에 `최근방문기록`과 `주요기록`(북마크·공지 아이콘, @멘션, 작성자·날짜)을 둔다. 오른쪽은 폼이다. 비어 있으면 `최근방문기록이 없습니다.`를 쓴다. (PrtRnLLTnOM@103, jHWTogR7JSc@205)
- **세그먼트**: `공단청구 | 비청구 | 자보청구`, `월청구 | 주청구`, `수가 | 약가 | 치료재료대`. 선택지가 2–4개이고 서로 배타적이면 셀렉트 대신 세그먼트를 쓴다.
- **조건부 필드**: 결제수단 토글 4개(`카드▾ 현금 할인금 선납금`) → 선택에 따라 필드 묶음이 바뀐다. 법규 안내는 ⓘ 회색 문장으로 필드 근처에 둔다. 금액 입력에는 접미사 `원`과 링크 `전액 입력`을 둔다. (Jn_sfEzZ7hg@28, @31)
- **검색해서 채우기**: 코드 입력 옆 tint 버튼 `검색하기` → 마스터 DB 팝오버 → 선택하면 코드·성분·이름·제조사가 채워진다. (0z9cgDYJXLE@103)
- **겹친 모달**: 보조 다이얼로그(가족추가, 단축어 지정)는 부모 모달 위에 더 작게 뜬다. 2단까지만 쓴다.
- **로딩**: 모달 자리에 흰 박스, 가운데 스피너, 회색 한 줄 문구 `환자 정보를 불러오고 있습니다…`를 둔다.

## 8. 피드백

- **토스트** `.p-toast`: 하단 가운데, `#383850` pill, 높이 44, 왼쪽에 청록 원 ✓, 흰 문장 1줄. 되돌릴 수 있으면 오른쪽에 `되돌리기` 링크를 둔다. 문장은 `○○을 추가했습니다.`, `발급이 완료되었습니다.`, `예약이 취소되었습니다.` 같은 형태다.
- **확인 다이얼로그** `.p-confirm`: 폭 360, 빨간 ⚠, 질문 bold, 설명(비용·즉시 적용 안내), 선택적 사유 입력(밑줄형 + ✏), `취소` `확인`. (jHWTogR7JSc@232, @304)
- **빈 상태**: 아이콘 + 진한 한 줄 + 회색 보조 한 줄(`생성된 원청구서가 없습니다.` / `상단 버튼을 통해 원청구서를 생성해보세요!`). 일러스트는 홈과 빈 작업면에서만 쓴다. (335HY52YPGA@52)
- **테이블 로딩**: 첫 행 자리에 `··· 아이템을 불러오는 중입니다.` 한 줄을 둔다. (krSw2ooCF1c@115)
- **버튼 진행 상태**: `내보내기`와 `생성` 버튼은 제자리에서 스피너로 바뀐다.

## 9. 일정(예약)

- **설정과 운영을 나눈다.** `관리 > 병원 > 스케줄`에서 리소스별 이름·색, 방문목적, 기간, 슬롯 간격(10/15/20/30/60분), 슬롯당 정원, 요일별 업무시간 슬라이더(점심 간격 포함, `일괄적용`), `법정공휴일 스케줄 생성하지 않음`, CRM 알림 토글을 정의한다. 예약 화면은 그 결과를 그린다. (jHWTogR7JSc@28–82)
- 월간 달력 셀을 클릭하면 단발 이벤트를 등록하거나(`E` 접두 칩) 그날을 비활성화한다(툴팁 + 토스트). 일요일·공휴일 숫자는 빨강, 오늘은 파란 원으로 표시한다. (jHWTogR7JSc@91–100)
- **예약 화면**: 왼쪽 27%에는 미니 달력(날짜 아래 `예약/정원`, 선택일은 파랑 pill)과 예약 테이블(`예약 n · 접수 n · 예약취소 n · 전체 n`, 열 `시간 | 환자정보 | 예약자정보 | 스케줄 ▼ | 방문목적`)을 둔다. 오른쪽에는 시간 그리드(헤더: 날짜 bold, 리소스 아바타 토글, `일별|주별` 세그먼트, `‹ 오늘 ›`)를 둔다. (jHWTogR7JSc@109, @157)
- 슬롯 블록: 리소스 색 1px 테두리 + 옅은 채움, radius 4. 왼쪽 위에 `14:15-14:30`(리소스 색 10px bold), 오른쪽 위에 예약 수를 쓴다. hover하면 블록 아래에 `+ 새 예약`이 나타난다. 예약이 있으면 블록 안에 `1 이름 목적` 행을 둔다. 현재 시각은 전체 폭 빨간 1px 선으로 표시한다.
- 생성 흐름: 슬롯 → `+ 새 예약` → 환자 검색 모달 → (없으면) `신환예약` 폼. 리소스·날짜·시간은 미리 채워진다. 신환 폼은 `환자정보 / 예약정보(☑ 환자와 동일) / 스케줄정보(회색 섹션) / 예약메모` 순서다. (jHWTogR7JSc@166–172)
- 정원 초과 시 시간 필드 옆에 빨강 `ⓘ 예약 슬롯이 가득 찬 시간입니다.`를 띄운다. 취소는 빨강 아웃라인 `예약취소` → 사유 입력 확인 → 토스트 → `예약취소` 탭으로 이동한다. 드래그 이동은 영상에서 관찰되지 않았다.

## 10. 검토·제출(청구)

- **작업 안 사전 점검**: 툴바 토글 `심사점검모드 ✓`를 켜면 해당 섹션 안에 살구색 칩 `상병점검 1`이 나타난다. 칩을 누르면 2분할 모달이 열린다. 왼쪽은 `점검 리스트 n` 대기열, 오른쪽은 기준(`보험인정기준`, 회색 박스) → `추천상병 검색` → 선택 행 박스 → 푸터 `점검 종료` │ `건너뛰기` `상병 입력 1`이다. 해결할수록 n이 줄어든다. (335HY52YPGA@19–40)
- **배치 화면**: 하나의 흰 컨테이너 안에 왼쪽 배치 카드 목록(검색 + 카드 `2023년 02월 / 보험종류 건강보험 청구번호 - 청구건수 10건`, 선택하면 파랑 테두리), 오른쪽 상세를 둔다. 상세 구성은 다음과 같다. (335HY52YPGA@67)
  - 헤더: `2023년 02월 건강보험 ›` + 오른쪽 아웃라인 `보험자격 오류 6건`(숫자 빨강) + `↻`
  - KPI 박스 4열: `청구번호 · 청구건수 · 진료비총액 · 청구총액`
  - 탭 `명세서내역 | 제외내역`, 밑줄형 검색, 테이블(`환자번호 | 환자명 | 내원일 | 상태`). 오류 행에는 `⚠ 오류 2건`, hover하면 `제외하기` 링크가 나온다.
  - 푸터: 왼쪽 `원청구서 삭제`(빨강 아웃라인), 오른쪽 `발급하기`(파랑).
- 오류 행 → `명세서` 모달(4열 key-value + `점검내용` 연분홍 배너 행 `❗ 주상병 미기재 (접수번호: 233316)` + `차트열기`) → 원인 화면에서 수정 → 돌아와 `↻` → 건수·금액이 갱신된다. (335HY52YPGA@82–106)
- 발급하면 `발급완료` 회색 칩이 붙고, 번호가 부여되고, `제외내역` 탭이 없어지고, 주 버튼이 `내려받기`로 바뀐다(파일 다운로드).

## 11. 통계·인사이트

- **필터 줄**: 왼쪽 `[일별|월별|직접입력 ▾][날짜 📅][▼ 필터]`, 오른쪽 `[↗ 내보내기][↻]`. `직접입력`을 고르면 2개월 범위 달력이 열린다(시작·끝은 파란 원, 사이는 옅은 띠). 날짜가 없으면 `날짜를 선택해주세요.` 빈 상태를 보여 준다. (krSw2ooCF1c@52, @55)
- **요약 카드**(약 600px): 라벨–값 정의 리스트. 그룹은 회색 테두리 박스로 묶는다. 합계 행은 bold + 아래 선, 하위 항목은 `- ` 들여쓰기 + 회색 + 옅은 띠로 쓴다. (krSw2ooCF1c@22)
- **요약 → 상세**: 왼쪽에 선택 가능한 요약 카드(`미수 환자수 5명 / 총 미수건/ 미수 금액 11건/ 319,610원`, 선택하면 파랑 테두리), 오른쪽에 `미수 내역 11` + 밑줄 검색 + 테이블을 둔다. 행 → 미리보기 모달(`닫기` │ `차트열기`) → 작업 → 돌아오면 목록이 갱신되어 있다. (krSw2ooCF1c@73–88)
- **전체 폭 테이블**: 분류 열 헤더 안 `▼` 단일 선택 팝오버, 정렬 열 `↑/↓`. 텍스트 열이 남은 폭을 흡수한다. 금액은 오른쪽 정렬하고 셀 안에는 단위 없이 콤마만 쓴다. (krSw2ooCF1c@103)
- **월간 리포트**(홈에서 열림): 가운데 기간과 큰 제목, `01. 매출 분석` 번호 섹션, KPI 4칸(라벨 → 24px 값 → ▲빨강/▼파랑 % `이전 월 대비`), 형광펜이 들어간 서술 요약, 2열 차트. (WNIjUaqvL-I@16)
- **대시보드**: 툴바 `[기간별 보기|트렌드로 보기]` `[월단위로 보기][주단위로 보기]` 가운데 기간 bold, 오른쪽 배치 변경. 3열 같은 높이 카드이고, 카드 헤더는 `제목 + 단위: 만 원 + ⊕ + ×`, 범례는 하단 왼쪽이다. 서로 다른 단위는 막대 + 점선 이중 축, 비율은 도넛·pie-of-pie + 바깥 지시선 라벨(`일반진료: 53.01%`)로 그린다. 순위는 가로 막대로 내림차순 정렬한다. (WNIjUaqvL-I@22)
