# Pallet 디자인 토큰

1920×1080 녹화 프레임에서 ffmpeg로 영역 평균을 낸 값을 기준으로 정리했다. JPEG 압축 때문에 ±3 정도의 오차가 있다. 녹화가 확대·축소되어 있어 px는 실제 CSS 기준으로 환산한 권장값이다. 근거는 `영상ID@초` 형식이며, [video-evidence.md](video-evidence.md)에서 링크를 찾을 수 있다.

### 리소스(스케줄) 색 페어

리소스마다 색 하나를 정해 **옅은 채움 + 진한 글자·테두리**로 모든 화면(월간 칩, 열 제목, 슬롯 블록, 필터 아바타)에 같이 쓴다.

| 이름 | 채움 | 칩 | 글자·테두리 |
|---|---|---|---|
| blue | `#F4F7FD` | `#E0E8FC` | `#5A7FCF` |
| red | `#FDF4F3` | `#FCE8E4` | `#D9695C` |
| green | `#F2FAF5` | `#DDF2E4` | `#3E9A62` |
| violet | `#F6F4FD` | `#E7E2FA` | `#7A62CC` |
| amber | `#FDF8EE` | `#FBEDCC` | `#B9831E` |

### 차트 팔레트 (인사이트, WNIjUaqvL-I@22)

`#357EFB` 파랑(주 시리즈) → `#5355FD` 인디고 → `#6E61E5` 바이올렛 → `#4BD4E3` 시안 → `#E8896D` 코랄 → `#35BE6C` 그린 → `#F5C142` 노랑. 이중 축의 보조 선은 주황 점선 `#F0A040`이다. KPI 증감은 증가 ▲ 빨강, 감소 ▼ 파랑으로 쓴다(국내 관례).

## 형태와 깊이

- radius: 칩·이벤트 블록 4 / 입력·버튼·내부 박스 6 / 카드·팝오버 8 / 모달 12 / 생성 모달 16 / 세그먼트·토스트·선택 날짜는 pill.
- 그림자: 고정 카드에는 0. 떠 있는 레이어에만 `0 8px 24px rgba(30,40,70,.14)`, 모달은 `0 16px 48px rgba(30,40,70,.18)`.
- 선택·포커스는 파란 1px 테두리(카드), 입력 포커스는 2px 링.
- 세그먼트 컨트롤은 회색 트랙 `#EFF1F5` 안에서 선택한 칸만 흰 박스로 둔다.
