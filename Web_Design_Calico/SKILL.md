# Web_Design_Calico · 삼색고양이 디자인 시스템

삼색고양이는 **넓은 흰 털 위에 경계가 또렷한 검은 패치와 주황 패치**가 비대칭으로 얹혀 있고, 같은 무늬를 가진 고양이는 없다. 성격은 조용하고 정돈되어 있지만 필요한 순간에는 정확하게 반응한다. Calico UI는 이 두 가지, 즉 **코트(배색·형태)**와 **성격(움직임·피드백·말투)**를 규칙으로 바꾼 것이다.

- 바로 쓰는 CSS: [assets/calico.css](assets/calico.css) (토큰 `--c-*`, 클래스 `.c-*`, 라이트/다크 포함)
- 색·크기·대비 값: [references/tokens.md](references/tokens.md)
- 시그니처 컴포넌트 마크업과 화면 레시피: [references/patterns.md](references/patterns.md)
- 동작 예제: [index.html](index.html) (`node server.cjs` → http://127.0.0.1:4173)

한 문장 요약:

> **흰 털이 화면을 차지하고, 차콜 패치가 구조를 잡고, 주황 패치는 딱 한 곳에서 시선을 부른다.**

---

## 1. 먼저 정할 것 (구현 전에 답한다)

1. **화면 유형:** 랜딩 / 서비스 소개 / 앱 / 대시보드 / 콘텐츠 / 관리. 정보 밀도와 패치 크기가 여기서 정해진다(§7).
2. **이 화면의 대표 패치(Signature Patch)는 어디인가.** 히어로 밴드, 대표 지표, 추천 콘텐츠, 푸터 중 **하나**를 차콜 패치로 정한다. 대표 패치가 없으면 삼색이가 아니라 흰 고양이다.
3. **주황이 불러야 할 단 하나의 행동.** 화면의 주 CTA 1개. 주황 면 패치를 쓴다면 그것과 같은 의미여야 한다.
4. **장난기 레벨(§6):** 0 사무실 / 1 기본 / 2 놀이. 업무·관리 화면은 0, 일반 서비스는 1, 브랜드·이벤트·온보딩은 2. 정하지 않았으면 **1**.

## 2. 코트 규칙 — 배색

### 2.1 삼색 비율

| 털 | 토큰 | 화면 면적 | 쓰는 곳 |
|---|---|---|---|
| 흰 털 Fur | `--c-fur` `--c-belly` `--c-cream` | **65–80%** | 페이지 바탕, 카드·입력 면, 보조 섹션(크림) |
| 검은 패치 Ink | `--c-ink` `--c-text*` | **15–25%** | 본문·제목 글자 **+ 실제 면 1–2개**(대표 패치, 푸터, 토스트, 코드 블록, 다크 사이드바) |
| 주황 패치 Ginger | `--c-ginger` `--c-ginger-ink` | **5–10%** | 주 CTA, 활성 상태(꼬리), 포커스 링, 패치 태그 1개 |
| 젤리 Bean | `--c-bean` | **1% 미만** | 좋아요·저장·새 알림 점. 선택 사항 |

핵심: **차콜은 글자로만 존재하면 안 된다.** 화면마다 최소 1개는 면(patch)으로 등장해야 삼색으로 읽힌다. 반대로 주황이 면적 10%를 넘으면 치즈 고양이(오렌지 태비)가 된다.

### 2.2 패치는 섞이지 않는다

삼색이의 무늬는 경계가 또렷하다. 색이 번진 고양이는 삼색이가 아니라 고등어·턱시도·카오스(tortoiseshell)다.

- 주황 ↔ 차콜 ↔ 흰색 사이에 **그라디언트 금지.** 코트 스트립처럼 여러 색이 이어질 때도 하드 스톱만 쓴다.
- 반투명 오버레이로 주황을 흐리게 깔지 않는다. 옅은 주황이 필요하면 `--c-ginger-soft` 단색을 쓴다.
- 주황 위에 차콜 텍스트, 차콜 위에 주황 텍스트(`--c-ginger-on-ink`)는 허용. **흰 글자를 넓은 `--c-ginger` 면 위에 쓰지 않는다**(3.2:1). 흰 글자 버튼은 `--c-ginger-ink`(5.1:1).

### 2.3 패치는 비대칭이다

같은 무늬의 삼색이는 없다. 대칭으로 나눈 색면은 국기나 체크무늬처럼 보인다.

- 주황 패치와 차콜 패치를 좌우·상하로 거울처럼 배치하지 않는다.
- 3열 카드를 주황·차콜·크림으로 번갈아 칠하지 않는다. 반복 요소는 모두 흰 털이고, 패치는 **그중 하나**에만 얹는다.
- 패치끼리는 **맞닿을 수 있다.** 차콜 패치 모서리에 주황 패치 태그가 걸쳐 붙는 `맞닿음(touch)`이 Calico의 대표 장면이다(§4.2).

### 2.4 패치 개수 상한 (한 뷰포트 기준)

```text
차콜 면 패치   최대 2  (대표 패치 1 + 푸터/토스트 같은 기능 면 1)
주황 면 패치   최대 1  (패치 태그 또는 주황 지표 카드 중 하나)
주황 채움 버튼 최대 1  (주 CTA)
코트 스트립    페이지당 1
```

## 3. 코트 규칙 — 형태

- **컴포넌트는 반듯하게, 패치만 부드럽게.** 버튼·입력 6px, 카드 8px, 다이얼로그 12px. 패치 면만 한 모서리가 큰 `--c-radius-patch: 28px 6px 6px 6px`을 쓴다. 고양이 등의 곡선 같은 단 하나의 둥근 모서리다.
- 네 모서리가 모두 큰 둥근 카드(`rounded-2xl` 류)는 쓰지 않는다. 귀여움은 둥글기가 아니라 **패치와 동작**에서 나온다.
- 구분은 그림자가 아니라 **수염선**(1px `--c-whisker`)으로 한다. 그림자는 드롭다운·다이얼로그·토스트처럼 실제로 떠 있는 것에만 약하게 쓴다.
- 카드는 독립된 대상(프로젝트 1건, 글 1편)에만 쓴다. 섹션을 나누려고 카드를 쓰지 않는다. **Card is not a layout system.**

## 4. 시그니처 컴포넌트

마크업과 상세 규칙은 [references/patterns.md](references/patterns.md). 클래스는 [assets/calico.css](assets/calico.css).

| 이름 | 고양이 | UI 역할 | 클래스 |
|---|---|---|---|
| 코트 마크 | 세 가지 털색 | 로고 옆 3줄 무늬(주황→차콜→크림 순서 고정) | `.c-coat-mark` |
| 코트 스트립 | 등 무늬 | 페이지 최상단 4px 불규칙 3색 띠. 페이지당 1회 | `.c-coat-strip` |
| 패치 | 검은 패치 | 대표 콘텐츠를 담는 차콜 면. 한 모서리만 큼 | `.c-patch` `.c-patch--cream` |
| 패치 태그 | 주황 패치 | 차콜 패치 모서리에 맞닿는 주황 라벨. 1개 | `.c-patch-tag` |
| 꼬리 | 꼬리 | 활성 탭·내비 아래/옆의 2px 주황 표시, 끝만 둥글고 미끄러지듯 이동 | `.c-tail` `.c-nav` |
| 귀 쫑긋 | 귀 | 클릭 가능한 카드 hover/focus 때 윗선 2px가 주황으로 섬. 떠오르지 않음 | `.c-card--ears` |
| 수염선 | 수염 | 1px 구분선 | `.c-whisker` |
| 고양이 눈 | 눈 | 주황 2px 포커스 링 + 3px 간격 | 공통 `:focus-visible` |
| 젤리 점 | 발바닥 젤리 | 좋아요·저장·새 알림의 8px 분홍 점. 글자 금지 | `.c-bean` |
| 골골 토스트 | 골골송 | 차콜 면 + 주황 점. 8px만 올라오며 나타나고 3초 후 사라짐 | `.c-toast` |
| 조용한 빈 상태 | 식빵 자세로 기다림 | 빈 목록·검색 결과 없음·첫 사용. 그림 없이 코트 마크 + 한 줄 + 버튼 1개 | `.c-empty` |

### 4.1 대표 패치 쓰는 법

```text
흰 털 ─────────────────────────────────────────────
  Eyebrow · 제목 · 설명 · [주 CTA] [보조]
                                     ┌── 패치 태그(주황) ──┐
  ╭──────────────────────────────────┴─────────────────┐
  │  차콜 패치: 제품 화면 / 대표 지표 / 추천 글          │
  └────────────────────────────────────────────────────┘
흰 털 ─────────────────────────────────────────────
```

- 패치 안의 내용은 **실제 제품 화면·핵심 수치·대표 콘텐츠**여야 한다. 장식용 빈 차콜 박스 금지.
- 패치 안 버튼은 주황 채움 + 차콜 글자, 보조 버튼은 투명 + 밝은 테두리.

### 4.2 맞닿음 (touch)

패치 태그는 차콜 패치 윗변에 걸쳐 절반은 흰 털 위, 절반은 차콜 위에 있다. 두 패치가 **경계를 공유**하되 겹쳐 그림자를 만들지 않는다. 화면당 1회.

## 5. 성격 규칙 — 움직임·피드백·말투

### 5.1 조용한 발걸음 (Motion)

```css
--c-paw: 180ms;    /* 색·배경·테두리 */
--c-stalk: 240ms;  /* 꼬리 이동, 토스트 등장 */
--c-ease: cubic-bezier(.2, .7, .2, 1);  /* 사뿐히 다가와 멈춤. 튕김 없음 */
```

허용: 꼬리 미끄러짐, 귀 쫑긋(윗선 색), 골골 토스트 8px 상승, 다이얼로그 페이드.
금지: 바운스·흔들기·무한 반복·스크롤 리빌·패럴랙스·커서 따라다니는 발자국·꼬리 흔드는 애니메이션. `prefers-reduced-motion`이면 모두 끈다.

### 5.2 고양이처럼 반응하기 (Feedback)

| 상황 | 고양이 | 처리 |
|---|---|---|
| hover | 귀를 세움 | 색·윗선만 변화. 크기·위치 변화 없음 |
| 선택/현재 위치 | 꼬리를 세움 | 주황 꼬리 + `--c-ginger-soft` 배경 |
| 성공 | 골골 | 골골 토스트. 한 문장 + 필요하면 `되돌리기` |
| 오류 | 하악 — 짧고 분명하게 | 필드 바로 아래 빨강(`--c-danger`) 한 문장. 원인 + 고칠 방법. 주황을 오류에 쓰지 않는다 |
| 로딩 | 기다리는 고양이 | 스켈레톤은 `--c-belly` 단색 블록. 반짝이는 쉬머 그라디언트 금지 |
| 비어 있음 | 식빵 자세로 기다림 | 코트 마크 + 상황 한 줄 + 다음 행동 버튼 1개. 일러스트 없음 |

### 5.3 말투 (Voice)

차분하고 짧은 존댓말. 집사에게 말하는 고양이가 아니라, **고양이처럼 군더더기 없는 안내자**다.

- 좋음: `저장했어요.` `검색 결과가 없어요. 다른 단어로 찾아보세요.` `프로젝트를 보관함으로 옮겼어요. 되돌리기`
- 피함: `야옹~ 저장 완료냥!` `🐾 앗! 문제가 생겼어요 😿` `Supercharge your workflow ✨`
- `냥`, 고양이 이모지, 발자국 이모지는 기능 UI(버튼·라벨·오류·폼)에서 금지. 장난기 레벨 2의 빈 상태·404·이벤트 문구에서만 화면당 1회 허용.

## 6. 장난기 레벨 (Playfulness)

같은 토큰으로 강도만 조절한다. 고양이는 **숨어 있을 때 더 고양이 같다.** 어떤 레벨에서도 고양이 그림(일러스트·실루엣·아이콘)은 쓰지 않는다. 고양이다움은 배색·패치·동작·말투로만 드러낸다.

| 요소 | 0 사무실 | 1 기본(기본값) | 2 놀이 |
|---|---|---|---|
| 삼색 비율·패치·꼬리·귀·수염 | ● | ● | ● |
| 코트 마크·코트 스트립 | 마크만 | ● | ● |
| 대표 차콜 패치 | 요약 지표 띠 정도 | ● | ● 크게(히어로 전체) |
| 패치 태그(맞닿음) | – | ● | ● |
| 젤리 점 | – | ● | ● |
| 빈 상태 코트 마크 | 문장만 | ● | ● + 404/완료 화면 |
| `냥`·고양이 이모지 | – | – | 빈 상태·404에서 1회 |

대상: 0 = ERP·MES·관리자·금융 / 1 = SaaS·서비스·콘텐츠 / 2 = 브랜드 소개·이벤트·온보딩·커뮤니티.

## 7. 레이아웃·글자·화면 유형

**컨테이너:** 1200px, 좌우 24px(모바일 20px). 읽기 폭 760px. 섹션 간격 64–96px, 120px 이상 반복 금지.

**글자:** Pretendard 우선, 영문·숫자 Inter. 제목은 굵고 짧게(`700`, 자간 -0.03em, 줄높이 1.3), 본문 16px/1.65, 숫자는 `font-variant-numeric: tabular-nums`. 그라디언트 글자·전체 대문자 제목·과한 자간 금지. 제목 색은 `--c-ink`, 강조 단어 1개만 `--c-ginger-ink` 허용.

```text
Display 44/700  H1 34/700  H2 26/700  H3 21/600
Body L 18/400   Body 16/400  Small 14/500  Caption 12/400   (모바일 Display 34, H1 28)
```

| 화면 | 대표 패치 | 밀도 | 메모 |
|---|---|---|---|
| 랜딩·서비스 소개 | 히어로 아래 제품 화면을 담은 차콜 패치 + 패치 태그 | 중하 | 히어로 → 대표 패치 → 기능 2–3개(50/50 교차) → 차콜 푸터 CTA |
| SaaS 앱 | 다크(차콜) 사이드바 **또는** 상단 요약 띠 중 하나 | 중 | 사이드바를 차콜로 하면 본문엔 차콜 면 패치를 더 두지 않는다 |
| 대시보드 | 핵심 지표 1개를 주황 면 패치, 나머지 지표는 흰 털 | 중 | 표는 수염선만, 카드 안에 표를 넣지 않는다 |
| 콘텐츠·아티클 | 추천 글 1편을 크림 또는 차콜 패치 | 중하 | 인용문은 왼쪽 주황 꼬리 3px + `--c-belly` |
| 관리·ERP (레벨 0) | 상단 요약 지표 띠(차콜) | 중상 | 배색·꼬리·수염만 |

모바일: 단순 축소가 아니라 재배치. 대표 패치는 전체 폭, 패치 태그는 패치 안쪽 왼쪽 위로 옮긴다. 사이드바는 가로 스크롤 탭 + 꼬리.

## 8. 밤 고양이 — 다크 모드

다크 모드는 색 반전이 아니라 **밤에 보는 삼색이**다. 흰 털은 따뜻한 먹색(`#1E1B19`), 차콜 패치는 더 깊은 검정(`#0F0D0C`), 주황은 조금 밝게(`#E8915C`) 올려 눈처럼 빛나게 한다.

- 같은 토큰 이름을 쓴다. 컴포넌트에 hex를 직접 쓰지 않는다.
- 다크에서 주 CTA는 주황 채움 + 먹색 글자(7.0:1).
- 순백(`#FFF`) 글자 대신 크림(`#F3ECE3`)을 쓴다.
- `prefers-color-scheme`를 따르고 `data-theme="light|dark"`로 덮어쓸 수 있게 한다([assets/calico.css](assets/calico.css)).

## 9. 금지 목록

**고양이가 아닌 것**
- 오렌지 그라디언트, 주황→차콜 그라디언트, 반짝이·글로우·글래스모피즘
- 주황 면이 10% 초과(치즈 고양이), 차콜 면이 없음(흰 고양이), 세 색을 고르게 1/3씩(국기)
- 퍼플/블루 AI 스타트업 배색, Sparkle 아이콘, 의미 없는 배지

**고양이를 과하게 쓰는 것**
- 리스트 불릿·아이콘을 발자국으로 대체, 고양이 이모지를 UI 아이콘으로 사용
- 고양이 그림 전반: 일러스트·실루엣·귀 달린 아바타·고양이 아이콘·발자국 패턴
- 꼬리 흔들기·눈 깜빡임 같은 장식 애니메이션
- 고양이 사진·3D 캐릭터·AI 생성 이미지

**일반 품질**
- 카드 남발, 모든 요소 둥글게, 카드마다 그림자, 너무 작은 글자(본문 14px 미만), 콘텐츠 없는 섹션

## 10. 설계 순서 (에이전트용)

1. 화면 유형과 사용자의 첫 행동을 정한다.
2. 콘텐츠 순서(Primary → Secondary → Supporting)를 정한다.
3. **대표 패치 위치 1곳**과 **주황이 부를 행동 1개**를 정한다.
4. 장난기 레벨을 정한다(기본 1).
5. 1200px 컨테이너·그리드로 흰 털 레이아웃을 먼저 짠다. 카드부터 만들지 않는다.
6. 대표 패치·패치 태그·꼬리·귀·수염을 얹는다.
7. 피드백(골골 토스트·하악 오류·조용한 빈 상태)과 말투를 채운다.
8. 다크 모드 토큰을 확인한다.
9. §11 점검표를 돌린다.

[assets/calico.css](assets/calico.css)를 그대로 가져다 쓰는 것을 우선한다. 프레임워크(Tailwind, shadcn/ui)를 쓰더라도 토큰 값은 이 파일과 같게 맞추고, shadcn 기본 radius·그림자·색은 덮어쓴다.
