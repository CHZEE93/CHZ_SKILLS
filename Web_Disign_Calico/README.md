# Calico UI Preview

디자인 검토용 동작하는 Preview입니다. 최종 재사용 Skill은 검토 후 별도로 정리합니다. 기존 SKILL.md는 수정하지 않았습니다.

## 실행

이 폴더에서 다음 명령을 실행합니다. Node.js 외 추가 패키지는 필요하지 않습니다.

```powershell
node server.cjs
```

http://127.0.0.1:4173 에 접속합니다. 이미 서버가 실행 중이면 다시 실행하지 않아도 됩니다. 종료는 실행한 터미널에서 Ctrl+C입니다. 서버 없이 index.html을 브라우저로 열어도 UI가 동작합니다.

## 파일

- index.html: 페이지 셸과 모달
- styles.css: 중앙 CSS 토큰, 컴포넌트, 반응형 스타일
- app.js: 재사용 렌더링 함수, 샘플 데이터, 입력 검증과 인터랙션
- server.cjs: 로컬 전용 정적 서버
- preview.png: Preview 화면 캡처

## 검토할 화면

Overview, 전체 컬러 팔레트, 한글 타이포 8단계, 버튼 상태표, 폼, 카드 3종, 서비스 내비게이션, 콘텐츠 목록, 프로젝트 관리, 아티클 상세를 포함합니다.

검색·카테고리/상태 필터·더 보기·프로젝트 추가·입력 검증·알림 스위치·아티클 저장·모바일 메뉴를 조작할 수 있습니다. 데이터는 현재 페이지 세션의 데모이며 새로고침하면 초기화됩니다. 로그인/회원가입은 실제 인증이 아닌 스타일 확인용 데모입니다.

브랜드 원색 #D9773F는 보존했습니다. 작은 흰색 버튼 문구의 대비를 위해 CTA는 #AE5429를 사용합니다. 비활성 외 안내 문구는 Secondary 색상을 사용합니다. Pretendard는 고정 버전 CDN에서 로드하며 네트워크를 사용할 수 없으면 시스템 폰트로 대체됩니다.

## 확인

```powershell
npm.cmd run check
```

JavaScript 문법 검사를 실행합니다. 프레임워크와 TypeScript가 없는 정적 프로젝트라 별도의 build/typecheck는 없습니다.

브라우저에서 1440/768/390px 폭의 페이지 가로 넘침, 검색, 프로젝트 추가와 집계, 유효한 폼 제출, 모바일 메뉴, 키보드 카테고리 필터 및 완료 프로젝트 16개 표시를 확인했습니다. 전체 접근성 인증이나 모든 브라우저의 호환성 검증을 의미하지 않습니다.

참고 사이트: https://www.wishket.com/ 및 https://yozm.wishket.com/magazine/ . 위시켓의 정보 구조를 확인했으며 요즘IT 페이지는 자동 조회에 실패하여 사용자 제공 디자인 기준을 적용했습니다. 레이아웃·카피·브랜드 자산을 복제하지 않았습니다.
